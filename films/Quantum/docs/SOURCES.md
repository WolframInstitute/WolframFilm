## Media

All URLs below were checked: each returns the file itself (`image/jpeg`, `application/pdf`, `video/mp4`, …) and
not an HTML page.  Wikimedia `upload.wikimedia.org` URLs are the "Original file" links with the `?utm_…`
tracking suffix removed.  **Two practical notes for `Import[url]`:** (1) upload.wikimedia.org rate-limits
(HTTP 429) clients that fetch many files quickly, or that send no descriptive User-Agent — fetch once, cache
locally (e.g. `URLDownload` into the film's asset folder) and import from disk; (2) the archive.org
`…/page/nNNN.jpg` URLs answer with a redirect to a `BookReaderImages.php` JPEG, which `Import` follows.

Copyright rule of thumb used below: works first published before 1931 are public domain in the US; in the EU a
photo or text is protected until 70 years after the author's death (Einstein d. 1955 → PD from 2026; Planck
d. 1947; Schrödinger d. 1961 → 2032; Heisenberg d. 1976 → 2047).
